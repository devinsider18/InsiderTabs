# InsiderTabs

InsiderTabs is a personal workspace for collecting websites, organizing them into groups, and keeping useful links easy to revisit. It brings a link library, a read-later queue, and named shortcuts together in one focused place.

## Your link workspace

**My Collections** is the central library. Create collections around projects, interests, or any other subject, then save links with a title and destination. Links can be edited, removed, or left outside a collection when they do not need a group.

When something is worth keeping but not opening right away, add it to **Next**. This reading queue gathers those links separately from the rest of the library, making it easier to return to them later. A saved link can be taken out of the queue without removing it from its collection.

## Shortcuts with To/Links

**To/Links** lets you give a website a short, memorable name. Each shortcut connects that name to its destination, so you can open a frequently visited site by looking up its name in the workspace. Shortcuts are managed independently from collected and queued links.

## Personal and local-first

InsiderTabs runs without an account or an app backend. Collections, saved links, shortcuts, and related workspace data are kept in the browser on the current device. This keeps the workspace personal, but it also means data is not automatically shared or synchronized across browsers and devices.

The settings include local data and backup options. Workspace data can be exported to a JSON file and restored later; Google Drive is available as an optional destination for manual backups. Settings also provide preference controls for the workspace.
